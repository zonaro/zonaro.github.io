ZONA DE PERIGO

      
Excluir repositório?

      
Esta ação exclui o repositório no GitHub, incluindo código, issues e outros dados associados. A recuperação não é garantida. Faça backup se necessário.

      

      
      
      
É necessário que o GitHub CLI tenha a permissão delete_repo. Se necessário, execute gh auth refresh -s delete_repo no terminal.
